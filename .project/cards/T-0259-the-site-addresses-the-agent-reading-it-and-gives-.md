Measured on 2026-09-14: `workfile.illodev.com` does not appear in web search for "workfile illodev", nor for `site:workfile.illodev.com`; the results are Glama, mcpservers.org, jsDelivr and GitHub releases. The deployed site answers 404 for `/robots.txt`, `/sitemap.xml` and `/llms.txt`, carries no structured data, and is one page whose only phrase — "the repository is the database" — is nothing anyone searches for. The header's "docs" link opens the demo SPA, which a crawler reads as an empty `<div id="root">` titled "Workfile", so none of the 4,666 lines under `packages/workfile/docs` are indexable anywhere.

The owner chose on 2026-09-14:

- **Design: a system prompt.** The landing addresses the agent a human sent to evaluate Workfile — `<system>`, `<tools>`, `<refusals>`, `<install>` — with a way out for the human reading over its shoulder.
- **An agent layer.** `robots.txt` that admits AI crawlers, `sitemap.xml`, `llms.txt` and `llms-full.txt`, Markdown served to `Accept: text/markdown` on every page with `Vary: Accept` and a `Link rel=alternate`, JSON-LD.
- **Indexable docs** at `/docs/*`, one page per `packages/workfile/docs/*.md`.
- **Comparison pages** for Backlog.md, Task Master and Beads, every third-party claim checked against a primary source on the date the page prints.
- **Stay on `workfile.illodev.com`.**

The site stays plain static on Vercel with no build step (`site/vercel.json`): generated pages are written by a script and committed, the way the stills are, and a check keeps them from drifting from their sources.

## Acceptance criteria

- [x] `site/index.html` is the system-prompt design, readable in light and dark, with no horizontal overflow from 360px to 1440px
- [x] Every command, MCP tool name, count and error code on the site is one the built CLI produces
- [x] Every HTML page has a Markdown twin advertised with `Link: rel="alternate"; type="text/markdown"`, and `Accept: text/markdown` on the HTML URL returns it with `Vary: Accept`
- [x] `/robots.txt`, `/sitemap.xml`, `/llms.txt` and `/llms-full.txt` exist, and the sitemap lists every HTML page
- [x] Every HTML page has its own title, description, canonical URL and JSON-LD that parses
- [x] `/docs/<name>` exists for every `packages/workfile/docs/*.md`, generated by one script
- [x] `pnpm run check` fails when a committed generated page differs from what the script writes
- [x] `/vs/backlog-md`, `/vs/task-master` and `/vs/beads` exist, and every claim about the third party links a primary source and prints the date it was checked
- [x] Verified on the deployed site with `curl` and a browser
