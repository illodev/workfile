`README.md` and `docs/getting-started.md` embed six images regenerated by
`pnpm run screenshots`. The app header is in every one of them, and it has
changed twice: the density and theme buttons became a settings gear (T-0198), and
the footer's claim strip ends in a chevron and gains a narrow-width badge
(T-0196). The work views also grew a search field (T-0195).

Nothing fails, because the script is manual and not in CI — which is the reason
the images drift in the first place, and the reason this is worth its own card
rather than a line in someone else's.

Worth deciding at the same time whether the regeneration belongs in the release
workflow, so that the pictures of the product are cut from the same commit as the
product.

## Acceptance criteria

- [x] The six embedded images show the shell as it currently ships.
- [x] The site assets are regenerated from the same run, not separately.
- [x] A decision is recorded on whether this runs on release or stays manual.
