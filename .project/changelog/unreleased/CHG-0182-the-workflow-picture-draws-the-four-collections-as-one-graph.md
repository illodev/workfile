The curated corpus behind the README stills declared no frontmatter relation from a doc or a memory record to a card, so the Workflow capture — the one view whose point is that a card, the decision behind it and the doc that tracks it are one object — drew 46 card nodes and dropped every other collection as isolated. The corpus now declares related on nine docs and every memory record, and cards and decisions on the fragments that shipped them; references name a record by title and resolve to IDs when the corpus is written. The capture shows 67 nodes and 79 edges across cards, docs and memory, and the README paragraph and the tour caption say so.
