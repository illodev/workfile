Every hierarchy rule read from the child upwards; nothing looked down, so a parent whose last child closed sat open until somebody's context paid for it. doctor now warns parent-all-children-closed on an open card whose every descendant is done, review, discarded, deferred or archived, walking the whole subtree so an open grandchild keeps it quiet. The warning says how many descendants delivered, which discarded children name a still-open twin, and the date of the parent's last note. It is a warning and --fix never touches it: on the board it was measured on, a parent with 68 children done and a parent with one child discarded and three pieces of work never carded look identical from the count. Measured on 2 550 cards the day it shipped: 2 findings, the same two the consuming repository's local prototype printed.
