Selecting a decision, learning or incident used to grow a 380px panel inside the lanes — and below a wide viewport it replaced them outright, so browsing record to record meant going back to the lanes each time. It now opens in the same overlay a card opens in: same width, same maximize toggle, same behaviour when you click the next tile.

The lanes keep their full width behind it at every viewport. The drawer itself is written once now and used by both views.
